# Work_Calculations
Pressure-Volume Work Integrator using Matplotlib and NumPy.

There is an ipynb file that compiles all of the files into one for easy use in Google Collab or Jupyter notebook. 

This system was made for Angstrom sized Hydrocarbon and Graphene Pores for easy calculations and analysis. Most constants are empirically fitted.
This code was designed for chemical calculations but can be used for general integration purposes.
